# File_I-O_Python
Project Name: Python File I/O Practice

Description:
This project is a beginner-friendly Python file that demonstrates how
File Input and Output (File I/O) works using Python built-in functions.
It is mainly focused on learning how to read, write, append, update,
and delete files using different file modes.

What you can learn from this code:
- How to open files using different modes (r, w, a, r+, w+, a+)
- How to read data from a file using read() and readline()
- How to write and append data into files
- How file pointers behave in different modes
- How to safely work with files using the "with" statement
- How to delete files using the os module

Practice Problems Included:
1. Create and write data into a file using Python
2. Replace specific words in a file (Java → Python)
3. Search whether a word exists in a file
4. Find the line number where a word occurs first
5. Count even numbers from a file containing comma-separated numbers

Who this project is for:
- Python beginners
- Students learning File Handling
- Anyone practicing basic Python logic with real file operations

Requirements:
- Python 3.x
- Basic understanding of Python syntax
- Local file system access

How to use:
1. Update the file paths according to your system
2. Run the Python file
3. Observe how file content changes after each operation
4. Modify the code to practice with your own files and data

Note:
This project is for learning and practice purposes only.
It focuses on clarity and understanding, not production-level optimization.
